# Change Log

All notable changes to the "zeus-vscode" extension will be documented in this file.

Check [Keep a Changelog](http://keepachangelog.com/) for recommendations on how to structure this file.

## [0.0.2]

- Syntax highlighting for interfaces: `interface`, `implements`, `extends`, `readonly`, `static`, `get`/`set`.
- Highlight type names in declarations and inheritance clauses (`class Foo`, `interface Foo`, `extends Base`, `implements Iface`).
- Added the missing control keywords `for`, `break`, `continue`, `super`.
- Fixed the primitive type list: added `u8`/`u16`/`u32`/`u64`, removed the non-existent `i128`/`f16`/`f128`.
