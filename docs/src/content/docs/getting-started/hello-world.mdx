Let's write your first Zeus program!

<Aside type="tip">
  Zeus programs use the `.zs` file extension.
</Aside>

## Your First Program

<Steps>

1. **Create a new file**

   ```bash
   touch hello.zs
   ```

2. **Write the code**

   ```zeus
   console.log("Hello, World 👋")
   ```

   That's it. No boilerplate!

3. **Run it**

   ```bash
   zeus run hello.zs
   # Output: Hello, World 👋
   ```

   When you want to keep the binary, use `zeus build`:

   ```bash
   zeus build hello.zs -o hello
   ./hello
   ```

</Steps>

## Understanding the Code

```zeus
console.log("Hello, World 👋")
```

- `console` — A global object available in every Zeus program, no import needed
- `.log` — Prints to stdout with a newline (like JavaScript's `console.log`)
- The string supports full UTF-8, including emojis 🎉

Zeus also has `console.error` (stderr) and `console.info` (stdout):

```zeus
console.log("info message")
console.error("something went wrong")
console.info("another info message")
```

---

## Controlling the Exit Code

By default, a Zeus program exits with code `0`. If you need to return a specific exit code — for scripts, CI, or error signaling — define a `main` function (optional) that returns `i32`:

```zeus
function main(): i32 {
  console.log("starting up")
  return 42  // this becomes the process exit code
}
```

```bash
zeus run exit-code.zs
echo $?  # 42
```

Module-level code runs directly — no `main()` required:

```zeus
console.log("module-level code runs")
```

## A Slightly Bigger Example

```zeus
class Greeter {
  public times: i32;

  constructor(t: i32) {
    this.times = t;
  }

  public greet() {
    let i = 0;
    while (i < this.times) {
      console.log("Hello!")
      i = i + 1;
    }
  }
}

let greeter = new Greeter(3);
greeter.greet();
```

```bash
zeus run greeter.zs
# Hello!
# Hello!
# Hello!
```
