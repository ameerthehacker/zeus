Let's write your first Zeus program! We'll create a simple program that demonstrates the basics.

<Aside type="tip">
  Zeus programs use the `.zs` file extension.
</Aside>

## Your First Program

<Steps>

1. **Create a new file**

   Create a file called `hello.zs`:

   ```bash
   touch hello.zs
   ```

2. **Write the code**

   Open `hello.zs` and add:

   ```zeus
   function main() {
     log("Hello, World 👋");
   }
   ```

3. **Run it**

   ```bash
   zeus run hello.zs
   # Output: Hello, World 👋
   ```

   That's it — `zeus run` compiles and executes in one step. When you want to keep the binary, use `zeus build` instead:

   ```bash
   zeus build hello.zs -o hello
   ./hello
   ```

</Steps>

## Understanding the Code

Let's break down what we wrote:

```zeus
function main() {
  log("Hello, World 👋");
}
```

### The `main` Function

Every Zeus program needs a `main` function—this is where execution begins:

```zeus
function main() {
  // Your code here
}
```

- `function` — Keyword to declare a function
- `main` — The entry point function name
- `()` — Takes no parameters, returns nothing

### The `log` Function

```zeus
log("Hello, World 👋");
```

- `log` — Built-in function to print to stdout
- Accepts a string (UTF-8 supported, including emojis! 🎉)

## A More Interesting Example

Let's try something with a class:

```zeus
class Greeter {
  public times: i32;

  constructor(t: i32) {
    this.times = t;
  }

  public greetCount(): i32 {
    return this.times;
  }
}

function main(): i32 {
  let greeter = new Greeter(5);
  return greeter.greetCount();
}
```

Save this as `greeter.zs` and run:

```bash
zeus run greeter.zs
echo $?
# Output: 5
```

## Working with Arrays

Here's an example using dynamic arrays:

```zeus
function main(): i32 {
  // Create an array of integers
  let numbers = new i32[];
  
  // Add some numbers
  numbers.push(10);
  numbers.push(20);
  numbers.push(30);
  
  // Access by index
  let first = numbers.get(0);
  let second = numbers.get(1);
  
  return first + second;  // Returns 30
}
```

Save as `arrays.zs` and run:

```bash
zeus run arrays.zs
echo $?
# Output: 30
```
