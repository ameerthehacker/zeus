Let's write your first Zeus program! We'll create a simple program that demonstrates the basics.

<Aside type="caution">
  Zeus doesn't have a `print` function yet. For now, we use the program's **exit code** to see output. Use `echo $?` after running to see the return value.
</Aside>

<Aside type="tip">
  Zeus programs use the `.zs` file extension.
</Aside>

## Your First Program

<Steps>

1. **Create a new file**

   Create a file called `hello.zs`:

   ```bash
   touch hello.zs
   ```

2. **Write the code**

   Open `hello.zs` and add:

   ```zeus
   function main(): i32 {
     let answer: i32 = 42;
     return answer;
   }
   ```

3. **Compile and run**

   ```bash
   zeus build hello.zs -o hello
   ./hello
   ```

4. **Check the result**

   The program's return value is the exit code. Check it with:

   ```bash
   echo $?
   # Output: 42
   ```

</Steps>

## Understanding the Code

Let's break down what we wrote:

```zeus
function main(): i32 {
  let answer: i32 = 42;
  return answer;
}
```

### The `main` Function

Every Zeus program needs a `main` function—this is where execution begins:

```zeus
function main(): i32 {
  // Your code here
}
```

- `function` — Keyword to declare a function
- `main` — The entry point function name
- `(): i32` — Takes no parameters, returns a 32-bit integer

### Variable Declaration

```zeus
let answer: i32 = 42;
```

- `let` — Declares a mutable variable
- `answer` — Variable name
- `: i32` — Type annotation (32-bit signed integer)
- `= 42` — Initial value

### Return Statement

```zeus
return answer;
```

Returns the value from the function. In `main`, this becomes the program's exit code.

## A More Interesting Example

Let's try something with a class:

```zeus
class Greeter {
  public times: i32;

  constructor(t: i32) {
    this.times = t;
  }

  public greetCount(): i32 {
    return this.times;
  }
}

function main(): i32 {
  let greeter: Greeter = new Greeter(5);
  return greeter.greetCount();
}
```

Save this as `greeter.zs` and run:

```bash
zeus build greeter.zs -o greeter
./greeter
echo $?
# Output: 5
```

## Working with Arrays

Here's an example using dynamic arrays:

```zeus
function main(): i32 {
  // Create an array of integers
  let numbers: i32[] = new i32[];
  
  // Add some numbers
  numbers.push(10);
  numbers.push(20);
  numbers.push(30);
  
  // Access by index
  let first: i32 = numbers.get(0);
  let second: i32 = numbers.get(1);
  
  return first + second;  // Returns 30
}
```

Save as `arrays.zs` and run:

```bash
zeus build arrays.zs -o arrays
./arrays
echo $?
# Output: 30
```
