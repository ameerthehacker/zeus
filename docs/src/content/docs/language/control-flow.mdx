Zeus provides standard control flow constructs for conditional execution and iteration.

## If Statements

### Basic If

```zeus
let age = 20;

if (age >= 18) {
  console.log("adult"); // age is 18 or over
}
```

### If-Else

```zeus
let score = 75;

if (score >= 60) {
  console.log("pass");
} else {
  console.log("fail");
}
```

### Chained If-Else

```zeus
function getGrade(score: i32): i32 {
  if (score >= 90) {
    return 4; // A
  } else {
    if (score >= 80) {
      return 3; // B
    } else {
      if (score >= 70) {
        return 2; // C
      } else {
        if (score >= 60) {
          return 1; // D
        } else {
          return 0; // F
        }
      }
    }
  }
}
```

## Conditions

Conditions must evaluate to `boolean`:

```zeus
let x: i32 = 10;
let y: i32 = 20;

if (x == y) { }   // equal
if (x != y) { }   // not equal
if (x < y)  { }   // less than
if (x <= y) { }   // less than or equal
if (x > y)  { }   // greater than
if (x >= y) { }   // greater than or equal

let flag: boolean = true;
if (flag)  { }     // boolean variable
if (!flag) { }     // negation

if (x > 0 && y > 0) { } // logical AND
if (x > 0 || y > 0) { } // logical OR
```

## For Loops

The `for` loop is ideal for counted iteration:

```zeus
let sum = 0;

for (let i: i32 = 0; i < 10; i++) {
  sum += i;
}

console.log(sum); // 45  (0+1+2+…+9)
```

### Syntax

```
for (initializer; condition; update) {
    // body
}
```

- **Initializer** — runs once before the loop starts (usually declares the loop variable)
- **Condition** — checked before each iteration; the loop runs while `true`
- **Update** — runs after each iteration (usually advances the counter)

All three parts are optional. Omitting the condition creates an infinite loop.

### Examples

Counting down:

```zeus
for (let i: i32 = 10; i > 0; i--) {
  // i = 10, 9, 8, …, 1
}
```

Stepping by 2:

```zeus
for (let i: i32 = 0; i < 10; i += 2) {
  // i = 0, 2, 4, 6, 8
}
```

Nested loops:

```zeus
let sum = 0;

for (let i: i32 = 0; i < 3; i++) {
  for (let j: i32 = 0; j < 3; j++) {
    sum += i * j;
  }
}

console.log(sum); // 9
```

## For…of Loops

A `for…of` loop iterates directly over the elements of an array — no index bookkeeping required. Declare the element binding with `const` (or `let`) and name the array to iterate over:

```zeus
let nums: i32[] = new i32[];
nums.push(10);
nums.push(20);
nums.push(30);

let sum = 0;
for (const n of nums) {
  sum += n;
}

console.log(sum); // 60
```

### Syntax

```
for (const element of array) {
    // body
}
```

- **element** — a fresh binding for each iteration; its type is inferred from the array's element type
- **array** — the array (any `T[]` expression) to iterate; it is evaluated **once**, before the loop starts

Use `let` instead of `const` when you want to reassign the element binding inside the loop body:

```zeus
for (let n of nums) {
  n = n * 2; // mutate the loop-local copy
  // ...
}
```

### Break and Continue

`break` and `continue` behave exactly as they do in a regular `for` loop:

```zeus
function firstEven(nums: i32[]): i32 {
  for (const n of nums) {
    if (n % 2 != 0) {
      continue; // skip odd numbers
    }
    return n;   // return the first even one
  }
  return -1;
}
```

### Iterating Objects

`for…of` works over arrays of any element type, including class instances:

```zeus
class Point {
  public x: i32;
  constructor(x: i32) { this.x = x; }
}

let pts: Point[] = new Point[];
pts.push(new Point(3));
pts.push(new Point(4));

let sum = 0;
for (const p of pts) {
  sum += p.x;
}

console.log(sum); // 7
```

<Aside type="note">
  `of` is a contextual keyword — it is only special inside a `for (...)` header, so you can still use `of` as a variable name elsewhere. `for…of` currently iterates arrays; other iterable types (such as strings) are not yet supported.
</Aside>

## While Loops

Repeat while a condition holds:

```zeus
let i = 0;
let sum = 0;

while (i < 10) {
  sum = sum + i;
  i = i + 1;
}

console.log(sum); // 45
```

### Factorial

```zeus
function factorial(n: i32): i32 {
  let result = 1;
  let i = 1;

  while (i <= n) {
    result *= i;
    i += 1;
  }

  return result;
}
```

## Break

`break` exits the innermost loop immediately. Code after `break` in the same iteration is skipped, and execution continues after the loop.

```zeus
let found = -1;

for (let i: i32 = 0; i < 100; i++) {
  if (i * i > 50) {
    found = i;
    break; // stop searching once the condition is met
  }
}

console.log(found); // 8  (8*8 = 64 > 50)
```

### Break in a While Loop

```zeus
function findFactor(n: i32): i32 {
  let i = 2;

  while (i < n) {
    if (n % i == 0) {
      break; // found a factor
    }
    i += 1;
  }

  return i; // smallest factor, or n if prime
}
```

### Break in Nested Loops

`break` only exits the **innermost** loop. The outer loop continues normally:

```zeus
let total = 0;

for (let i: i32 = 0; i < 5; i++) {
  for (let j: i32 = 0; j < 10; j++) {
    if (j == 3) {
      break; // exits only the inner loop
    }
    total += 1;
  }
  // outer loop continues here
}

console.log(total); // 15  (5 outer iters × 3 inner iters each)
```

<Aside type="caution">
  Using `break` outside of a loop is a compile error.
</Aside>

## Continue

`continue` skips the rest of the current iteration and moves to the next one. In a `for` loop the update expression (`i++`) still runs before the next condition check.

```zeus
let sum = 0;

// Sum only odd numbers 1..9
for (let i: i32 = 1; i <= 10; i++) {
  if (i % 2 == 0) {
    continue; // skip even numbers
  }
  sum += i;
}

console.log(sum); // 25  (1+3+5+7+9)
```

### Continue in a While Loop

<Aside type="tip">
  When using `continue` inside a `while` loop, make sure the loop variable is updated **before** `continue`, otherwise the loop may run forever.
</Aside>

```zeus
function sumOdd(limit: i32): i32 {
  let sum = 0;
  let i = 0;

  while (i < limit) {
    i += 1;          // advance first — otherwise infinite loop
    if (i % 2 == 0) {
      continue;       // skip even numbers
    }
    sum += i;
  }

  return sum;
}
```

### Continue in Nested Loops

Like `break`, `continue` only affects the **innermost** loop:

```zeus
let count = 0;

for (let i: i32 = 0; i < 3; i++) {
  for (let j: i32 = 0; j < 3; j++) {
    if (j == 1) {
      continue; // skips j == 1 in inner loop only
    }
    count += 1;
  }
}

console.log(count); // 6  (3 outer × 2 inner where j ≠ 1)
```

<Aside type="caution">
  Using `continue` outside of a loop is a compile error.
</Aside>

## Patterns

### Search with Break

The most idiomatic way to exit a loop once a result is found:

```zeus
function indexOf(arr: i32[], size: i32, target: i32): i32 {
  let idx = -1;

  for (let i: i32 = 0; i < size; i++) {
    if (arr.get(i) == target) {
      idx = i;
      break;
    }
  }

  return idx;
}
```

### Filter with Continue

Skip unwanted elements and only process the ones that match:

```zeus
function sumPositive(arr: i32[], size: i32): i32 {
  let sum = 0;

  for (let i: i32 = 0; i < size; i++) {
    if (arr.get(i) <= 0) {
      continue;
    }
    sum += arr.get(i);
  }

  return sum;
}
```

### Accumulator

```zeus
function sumArray(arr: i32[], length: i32): i32 {
  let sum = 0;
  let i = 0;

  while (i < length) {
    sum += arr.get(i);
    i += 1;
  }

  return sum;
}
```

### Maximum Value

```zeus
function findMax(arr: i32[], length: i32): i32 {
  if (length == 0) { return 0; }

  let max = arr.get(0);
  let i = 1;

  while (i < length) {
    if (arr.get(i) > max) {
      max = arr.get(i);
    }
    i += 1;
  }

  return max;
}
```

### Fibonacci (iterative)

```zeus
function fibonacci(n: i32): i32 {
  if (n <= 1) { return n; }

  let prev = 0;
  let curr = 1;

  for (let i: i32 = 2; i <= n; i++) {
    let next = prev + curr;
    prev = curr;
    curr = next;
  }

  return curr;
}
```
