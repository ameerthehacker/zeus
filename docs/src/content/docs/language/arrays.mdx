Zeus provides dynamic arrays that can grow and shrink at runtime.

## Creating Arrays

```zeus
let numbers = new i32[];           // Empty array
let preallocated = new i32[100];   // Pre-allocate capacity
```

## Basic Operations

```zeus
let arr = new i32[];

// Add elements
arr.push(10);
arr.push(20);
arr.push(30);        // arr = [10, 20, 30]

// Access elements (bracket notation or .get())
let first = arr[0];       // 10
let second = arr.get(1);  // 20

// Modify elements (bracket notation or .set())
arr[0] = 100;
arr.set(1, 200);     // arr = [100, 200, 30]

// Remove last element
let last = arr.pop();  // Returns 30, arr = [100, 200]

// Check length
let len = arr.length;  // 2
```

## Method Reference

<Aside type="tip">
  Methods are either **mutating** (modify the original) or **non-mutating** (return new arrays).
</Aside>

### Mutating Methods

| Method | Description |
|--------|-------------|
| `push(value)` | Add element to end |
| `pop()` | Remove and return last element |
| `set(index, value)` | Set element at index |
| `fill(value)` | Fill all elements with value |
| `clear()` | Remove all elements |
| `copy(source)` | Copy elements from another array |

### Non-Mutating Methods

These return **new arrays** without modifying the original:

| Method | Description |
|--------|-------------|
| `concat(other)` | Combine two arrays |
| `slice(start, end)` | Extract sub-array (end exclusive) |
| `reverse()` | Reverse element order |

### Search Methods

| Method | Description |
|--------|-------------|
| `indexOf(value)` | First index of value, or -1 |
| `lastIndexOf(value)` | Last index of value, or -1 |
| `includes(value)` | Returns `true` if value exists |
| `find(value)` | Returns element or default value |
| `findIndex(value)` | Same as `indexOf` |
| `isEmpty()` | Returns `true` if length is 0 |

## Non-Mutating Operations

```zeus
let arr = new i32[];
arr.push(1); arr.push(2); arr.push(3);

// concat - combine arrays
let other = new i32[];
other.push(4); other.push(5);
let combined = arr.concat(other);  // [1, 2, 3, 4, 5]
// arr is still [1, 2, 3]

// slice - extract portion (start inclusive, end exclusive)
let middle = combined.slice(1, 4);  // [2, 3, 4]

// reverse - reverse order
let reversed = arr.reverse();  // [3, 2, 1]
// arr is still [1, 2, 3]

// Chain operations
let result = arr.reverse().slice(0, 2);  // [3, 2]
```

## Searching

```zeus
let arr: i32[] = new i32[];
arr.push(10); arr.push(20); arr.push(30); arr.push(20);

arr.indexOf(20);      // 1 (first occurrence)
arr.lastIndexOf(20);  // 3 (last occurrence)
arr.indexOf(999);     // -1 (not found)
arr.includes(20);     // true
arr.includes(999);    // false
arr.isEmpty();        // false
```

<Aside type="note">
  `find(value)` returns the default value (0, false, or null) when not found. Use `indexOf` and check for -1 to distinguish.
</Aside>

## Multi-Dimensional Arrays

```zeus
// 2D array
let matrix = new i32[][];
matrix.push(new i32[]);
matrix.push(new i32[]);
matrix[0].push(1); matrix[0].push(2);
matrix[1].push(3); matrix[1].push(4);

let value = matrix[0][1];  // 2

// 3D array
let cube = new i32[][][];
cube.push(new i32[][]);
cube[0].push(new i32[]);
cube[0][0].push(42);
let v = cube[0][0][0];  // 42
```

## Object Arrays

```zeus
class Point {
  public x: i32;
  public y: i32;
  constructor(x: i32, y: i32) {
    this.x = x;
    this.y = y;
  }
}

let points = new Point[];
points.push(new Point(1, 2));
points.push(new Point(3, 4));

let p = points[0];
let sum = p.x + p.y;  // 3
```

## Practical Examples

### Sum Elements

```zeus
function sumArray(arr: i32[]): i32 {
  let sum = 0;
  for (let i: i32 = 0; i < arr.length; i++) {
    sum += arr[i];
  }
  return sum;
}
```

### Remove Element at Index

```zeus
function removeAt(arr: i32[], index: i32): i32[] {
  let before: i32[] = arr.slice(0, index);
  let after: i32[] = arr.slice(index + 1, arr.length);
  return before.concat(after);
}
```

### Matrix Class

```zeus
class Matrix {
  public data: i32[][];
  
  constructor(rows: i32, cols: i32) {
    this.data = new i32[][];
    for (let i: i32 = 0; i < rows; i++) {
      this.data.push(new i32[cols]);
    }
  }
  
  public get(row: i32, col: i32): i32 {
    return this.data[row][col];
  }
  
  public set(row: i32, col: i32, value: i32) {
    this.data[row][col] = value;
  }
}
```

## Bounds Checking

Zeus performs automatic bounds checking when reading from arrays. Accessing an index outside the valid range throws an `IndexOutOfBoundsException`:

```zeus
let arr: i32[] = new i32[];
arr.push(10);
arr.push(20);

let safe = arr[0];      // 10 - valid
let also_safe = arr[1]; // 20 - valid
let oob = arr[5];       // Throws IndexOutOfBoundsException!
```

<Aside type="caution">
  Reading from an invalid index throws an exception. Always ensure indices are within bounds or use try-catch to handle potential errors.
</Aside>

### Handling Bounds Errors

You can catch bounds errors using try-catch:

```zeus
function safeGet(arr: i32[], index: i32): i32 {
  try {
    return arr[index];
  } catch (e: Error) {
    console.log("Index out of bounds: " + e.message);
    return -1;  // Return default value
  }
}
```

### Safe Access Pattern

Check length before accessing:

```zeus
function getOrDefault(arr: i32[], index: i32, defaultValue: i32): i32 {
  if (index < 0) {
    return defaultValue;
  }
  if (index >= arr.length) {
    return defaultValue;
  }
  return arr[index];
}
```

<Aside type="note">
  Array writes using bracket notation (`arr[i] = value`) automatically extend the array if needed, so they don't throw bounds exceptions.
</Aside>
