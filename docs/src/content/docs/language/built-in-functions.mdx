Zeus provides built-in functions that are available globally without any imports.

## I/O Functions

### `log`

Prints a string to standard output, followed by a newline.

```zeus
log(message: string)
```

**Parameters:**
- `message` — A string to print

**Example:**

```zeus
function main() {
  log("Hello, World!");
  log("Zeus supports UTF-8 🚀");
  
  let greeting: string = "Welcome to Zeus!";
  log(greeting);
}
```

**Output:**
```
Hello, World!
Zeus supports UTF-8 🚀
Welcome to Zeus!
```

<Aside type="tip">
  The `log` function fully supports UTF-8, including emojis and international characters. Each call to `log` automatically adds a newline at the end.
</Aside>

### Logging Byte Arrays

Since `u8[]` can be implicitly converted to `string`, you can log byte arrays by first converting them:

```zeus
function main() {
  let bytes: u8[] = new u8[];
  bytes[0] = 'H';
  bytes[1] = 'i';
  
  // Convert to string for logging
  let text: string = bytes;
  log(text);  // "Hi"
}
```
